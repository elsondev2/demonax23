# Checkers Game - Quick Start Guide

## 🎮 How to Play

### Starting a Game

1. **Navigate to Checkers**
   - Go to `/games/checkers` or click the Checkers app icon
   - You'll see your stats: Points, Wins, Losses, and Streak

2. **Choose Game Mode**
   - **Local Game** - Play with someone on the same device
   - **vs AI** - Challenge the computer (Easy/Medium/Hard/Expert)
   - **Arena** - Competitive match for points
   - **Friendly Match** - Play with online friends (no points)
   - **Watch Live Matches** - Spectate ongoing games

### Playing Against Friends

1. Select "Friendly Match" or "Arena"
2. Choose an online player from your contacts
3. They receive a challenge notification
4. When they accept, the game starts!
5. **You are RED** (first player)
6. **Opponent is BLACK** (second player)

### Game Rules

- **Move**: Click your piece, then click a valid square
- **Capture**: Jump over opponent pieces diagonally
- **King**: Reach the opposite end to become a King (can move backward)
- **Win**: Capture all opponent pieces

### During the Game

- **Your Turn**: "It's your turn!" message appears
- **Opponent's Turn**: "Waiting for opponent..." message
- **Live Updates**: Moves appear instantly for both players
- **Spectators**: See who's watching your game
- **Abandon**: Click "Abandon Game" to forfeit

### Spectating Games

1. Click "Watch Live Matches" from main menu
2. Browse active games showing:
   - Player names and colors
   - Current scores
   - Move count
3. Click "Watch Game" to spectate
4. See real-time moves as they happen
5. Click "Stop Watching" to leave

### After the Game

- See winner announcement
- View game stats (moves, mode, winner)
- Your profile updates automatically:
  - Points earned/lost
  - Win/loss record
  - Current streak
- Options: Start new game or return to apps

## 🎯 Game Modes Explained

### Local Game
- Two players on same device
- No points awarded
- Great for practice

### vs AI
- Four difficulty levels
- Points awarded based on difficulty:
  - Easy: 5 points
  - Medium: 10 points
  - Hard: 20 points
  - Expert: 30 points

### Arena
- Competitive multiplayer
- Bet points before game
- Winner takes double the bet
- Loser loses bet amount
- Affects your ranking

### Friendly Match
- Casual multiplayer
- 10 points for winner
- No points lost for loser
- Perfect for playing with friends

## 🏆 Scoring System

- **Win**: Earn points based on mode
- **Loss**: Lose points in Arena mode only
- **Streak**: Win consecutive games for achievements
- **Achievements**: Unlock badges for milestones

## 💡 Tips

1. **Plan Ahead**: Think 2-3 moves ahead
2. **Control Center**: Try to control the center squares
3. **Kings Are Powerful**: Protect your kings, target opponent's
4. **Force Jumps**: Set up situations where opponent must jump
5. **Watch Spectators**: See who's learning from your moves!

## 🐛 Troubleshooting

**Game not updating?**
- Check your internet connection
- Refresh the page
- Socket connection will auto-reconnect

**Can't see opponent's moves?**
- Make sure you're in the game room
- Check if game is still active
- Try rejoining via game URL

**Challenge not received?**
- Ensure opponent is online
- Check they haven't disabled notifications
- Try sending again
