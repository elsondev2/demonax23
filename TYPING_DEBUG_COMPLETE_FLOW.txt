═══════════════════════════════════════════════════════════════════════════════
🐛 TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════════════════

PROBLEM 1: No logs in User A console when clicking input
───────────────────────────────────────────────────────────────────────────────
SYMPTOMS:
- No "🔵 TYPING: Emitting typing event" log

CHECKS:
1. Is the input actually focused? (Check debugger "Your Typing Status")
2. Is socket connected? (Check debugger "Socket: 🟢 Connected")
3. Is conversationId valid? (Check debugger "Conversation ID")
4. Any JavaScript errors in console?

SOLUTIONS:
- Refresh the page
- Check if WYSIWYGMessageInput onFocus is being called
- Verify socket is initialized in useAuthStore


PROBLEM 2: Backend doesn't receive typing event
───────────────────────────────────────────────────────────────────────────────
SYMPTOMS:
- User A sees "🔵 TYPING: Emitting typing event"
- But no "🔵 BACKEND: Received typing event" in backend

CHECKS:
1. Is backend running?
2. Is WebSocket connection established?
3. Check network tab for WebSocket frames

SOLUTIONS:
- Restart backend server
- Check backend console for connection errors
- Verify socket.io is properly configured


PROBLEM 3: Backend can't find target user
───────────────────────────────────────────────────────────────────────────────
SYMPTOMS:
- Backend shows "❌ BACKEND: Target user not connected"

CHECKS:
1. Is User B logged in?
2. Is User B's socket connected?
3. Check getReceiverSocketId() function

SOLUTIONS:
- Have User B refresh the page
- Check userSocketMap in backend
- Verify User B's socket.userId is set correctly


PROBLEM 4: User B doesn't receive event
───────────────────────────────────────────────────────────────────────────────
SYMPTOMS:
- Backend shows "✅ BACKEND: userTyping event sent"
- But no "📥 RECEIVED: userTyping" in User B console

CHECKS:
1. Is User B's socket connected?
2. Is User B listening to "userTyping" event?
3. Check if event is being filtered

SOLUTIONS:
- Check User B's console for socket connection status
- Verify socket.on("userTyping") is registered in useChatStore
- Check if subscribeToMessages() was called


PROBLEM 5: Event received but not shown in UI
───────────────────────────────────────────────────────────────────────────────
SYMPTOMS:
- User B sees "📥 RECEIVED: userTyping"
- User B sees "✅ STORE: Updating state"
- But typing indicator doesn't appear

CHECKS:
1. Is User B in the same conversation?
2. Check debugger "Others Typing" section
3. Check if TypingIndicator component is rendered

SOLUTIONS:
- Verify conversationId matches in both windows
- Check ChatContainer's currentTypingUsers calculation
- Inspect TypingIndicator component props


PROBLEM 6: Typing indicator flickers
───────────────────────────────────────────────────────────────────────────────
SYMPTOMS:
- Indicator appears and disappears rapidly

CHECKS:
1. Check for rapid "userTyping" / "userStoppedTyping" events
2. Check debounce logic in setUserTyping

SOLUTIONS:
- Verify 1-second debounce is working
- Check if multiple typing events are being sent
- Verify TypingIndicator memo is working
