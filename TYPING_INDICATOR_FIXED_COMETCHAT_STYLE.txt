═══════════════════════════════════════════════════════════════════════════════
📊 HOW IT WORKS NOW
═══════════════════════════════════════════════════════════════════════════════

SCENARIO 1: User types a message
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. User types first character                                               │
│    └─ Send "startTyping" event (ONCE)                                       │
│    └─ Set isTyping = true                                                   │
│    └─ Start 3-second inactivity timer                                       │
│                                                                              │
│ 2. User types more characters                                               │
│    └─ Reset 3-second timer (no new events sent)                             │
│    └─ Reset timer again (no new events sent)                                │
│    └─ Reset timer again (no new events sent)                                │
│                                                                              │
│ 3. User stops typing for 3 seconds                                          │
│    └─ Timer fires                                                            │
│    └─ Send "endTyping" event                                                 │
│    └─ Set isTyping = false                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

SCENARIO 2: User clicks away
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. User is typing                                                            │
│    └─ isTyping = true                                                       │
│                                                                              │
│ 2. User clicks outside input (blur)                                         │
│    └─ Send "endTyping" event immediately                                     │
│    └─ Set isTyping = false                                                  │
│    └─ Clear timer                                                            │
└─────────────────────────────────────────────────────────────────────────────┘

SCENARIO 3: User sends message
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. User is typing                                                            │
│    └─ isTyping = true                                                       │
│                                                                              │
│ 2. User presses Enter or clicks Send                                        │
│    └─ Send "endTyping" event                                                 │
│    └─ Set isTyping = false                                                  │
│    └─ Clear timer                                                            │
│    └─ Send message                                                           │
└─────────────────────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════════════════
📚 COMETCHAT PATTERN REFERENCE
═══════════════════════════════════════════════════════════════════════════════

From CometChat docs:

START TYPING:
  CometChat.startTyping(typingNotification);
  - Called ONCE when user starts typing
  - Receiver gets onTypingStarted() callback

END TYPING:
  CometChat.endTyping(typingNotification);
  - Called ONCE when user stops typing
  - Receiver gets onTypingEnded() callback

OUR IMPLEMENTATION:
  socket.emit('typing', { ... });        // = startTyping
  socket.emit('stopTyping', { ... });    // = endTyping
