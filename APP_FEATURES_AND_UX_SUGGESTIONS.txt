📱 MOBILE UX IMPROVEMENTS & SIMPLIFICATIONS
═══════════════════════════════════════════════════════════════════════════════

🎯 HIGH PRIORITY - QUICK WINS
───────────────────────────────────────────────────────────────────────────────

1. SIMPLIFY MESSAGE INPUT TOOLBAR
   Current: Multiple buttons (attach, caption, emoji, audio, formatting)
   Suggestion:
   • Combine "attach" and "caption" into one button with dropdown
   • Move formatting toolbar to a slide-up panel (tap "+" to expand)
   • Keep only: [+] [Emoji] [Input] [Audio/Send]
   • Auto-switch audio button to send button when text is present

2. REDUCE MODAL OVERLOAD
   Current: Many modals (emoji, attachment type, caption, etc.)
   Suggestion:
   • Use bottom sheets instead of modals on mobile
   • Emoji picker as bottom sheet (easier thumb reach)
   • Attachment picker as bottom sheet with icons
   • Faster animations (200ms instead of 300ms+)

3. IMPROVE TYPING INDICATOR
   ✅ FIXED: Now uses focus/blur with 2-second inactivity timeout
   • Shows typing when input is focused
   • Hides after 2 seconds of inactivity
   • Positioned above message input (not in message area)
   • No more flickering on every keystroke

4. OPTIMIZE TOUCH TARGETS
   Current: Some buttons are small
   Suggestion:
   • Minimum 44x44px touch targets
   • Increase padding on message bubbles for easier long-press
   • Larger swipe area for reply gesture
   • Bigger emoji picker emoji buttons (currently good at 2xl)

5. SIMPLIFY CONTEXT MENUS
   Current: Long list of options in dropdown
   Suggestion:
   • Show only 3-4 most common actions initially
   • "More" button for additional options
   • Common actions: Reply, Copy, Delete, Edit
   • Less common: Forward, Pin, Report (in "More")


🎨 MEDIUM PRIORITY - UX POLISH
───────────────────────────────────────────────────────────────────────────────

6. IMPROVE SCROLL BEHAVIOR
   Current: Auto-scroll can be jarring
   Suggestion:
   • Smooth scroll only when near bottom
   • Show "scroll to bottom" button earlier (after 3-4 messages)
   • Add unread count badge on scroll button
   • Disable auto-scroll when user is reading old messages

7. OPTIMIZE IMAGE HANDLING
   Current: Images load in message bubbles
   Suggestion:
   • Show thumbnail with blur-up effect
   • Tap to expand (already implemented)
   • Add pinch-to-zoom in preview
   • Swipe between multiple images in conversation

8. STREAMLINE VOICE MESSAGES
   Current: Recording UI is good but could be simpler
   Suggestion:
   • Slide-to-cancel gesture (like WhatsApp)
   • Waveform visualization while recording
   • Tap-and-hold to record, release to send
   • Swipe up to lock recording for hands-free

9. IMPROVE MENTION SYSTEM
   Current: Dropdown appears above input
   Suggestion:
   • Show mentions inline as chips while typing
   • Highlight mentioned users in different color
   • Tap mention in message to view profile
   • Show mention count badge ("3 mentions")

10. ENHANCE GROUP CHAT UX
    Current: Group messages show sender name
    Suggestion:
    • Color-code users (consistent colors per user)
    • Smaller avatars in groups (save space)
    • Tap avatar to quick-reply to that person
    • Show "replying to [name]" indicator


⚡ LOW PRIORITY - NICE TO HAVE
───────────────────────────────────────────────────────────────────────────────

11. ADD QUICK REACTIONS
    • Long-press message → show 6 quick emoji reactions
    • Tap to add reaction (no need to open emoji picker)
    • Show reaction count on message bubble
    • Tap reaction to see who reacted

12. IMPROVE SEARCH
    • Add search bar in chat header
    • Search messages in current conversation
    • Highlight search results
    • Jump to message from search

13. ADD MESSAGE THREADS
    • Reply creates a thread
    • Show thread indicator on parent message
    • Tap to view thread in side panel
    • Useful for group chats

14. OPTIMIZE NETWORK USAGE
    • Compress images more aggressively on mobile data
    • Show data usage indicator
    • Option to disable auto-download on mobile data
    • Lazy load old messages

15. ADD OFFLINE SUPPORT
    • Cache recent messages locally
    • Queue messages when offline
    • Show offline indicator
    • Auto-send when back online
