🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: "Failed to initialize WebRTC: Permission denied"
SOLUTION:
  - Allow microphone/camera permissions in browser
  - Check browser settings
  - Try HTTPS (required for some browsers)

PROBLEM: "Connection state: failed"
SOLUTION:
  - Check firewall settings
  - May need TURN server for restrictive networks
  - Add TURN server in webrtcService.js iceServers config

PROBLEM: No audio/video
SOLUTION:
  - Check browser console for errors
  - Verify media devices are working
  - Check if tracks are enabled
  - Verify remote stream is received

PROBLEM: "Socket not connected"
SOLUTION:
  - Check backend is running
  - Verify WebSocket connection
  - Check CORS settings
