# Message Formatting - User Guide

## Quick Start

You can now format your messages with **bold**, *italic*, __underline__, and ~~strikethrough~~ text!

## Two Ways to Format

### 1. Using the Toolbar (Visual Method)

**Step 1**: Look for the three-dot icon (⋮) next to the microphone button in the message input

**Step 2**: Select the text you want to format (or leave cursor where you want to insert formatted text)

**Step 3**: Click the three-dot icon

**Step 4**: Choose your format:
- **B** - Bold
- **I** - Italic  
- **U** - Underline
- **St** - Strikethrough

**That's it!** Your text is now formatted.

### 2. Using Keyboard Shortcuts (Fast Method)

| Shortcut | Format | Example |
|----------|--------|---------|
| **Ctrl+B** (Cmd+B on Mac) | Bold | `**text**` |
| **Ctrl+I** (Cmd+I on Mac) | Italic | `*text*` |
| **Ctrl+U** (Cmd+U on Mac) | Underline | `__text__` |
| **Ctrl+Shift+X** (Cmd+Shift+X on Mac) | Strikethrough | `~~text~~` |

## How It Works

### With Selected Text
1. Type your message: `Hello world`
2. Select the word you want to format: `Hello |world|`
3. Press **Ctrl+B** or click **B** in the toolbar
4. Result: `Hello **world**`
5. Send your message - it will appear as: Hello **world**

### Without Selected Text
1. Place your cursor where you want formatted text
2. Press **Ctrl+B** or click **B** in the toolbar
3. A placeholder appears: `**text**` (with "text" selected)
4. Type your word to replace "text"
5. Result: `**important**`
6. Send your message - it will appear as: **important**

## Examples

### Making Announcements
```
Type: @everyone **Important Update**
Result: @everyone Important Update (bold)
```

### Emphasizing Points
```
Type: This is *really* important!
Result: This is really important! (italic)
```

### Showing Corrections
```
Type: Meeting is ~~Friday~~ **Monday**
Result: Meeting is Friday (strikethrough) Monday (bold)
```

### Highlighting Terms
```
Type: Remember to __save your work__
Result: Remember to save your work (underlined)
```

## Tips & Tricks

### Tip 1: Combine Formats
You can use multiple formats in one message:
```
**Bold** and *italic* and ~~strike~~ and __underline__
```

### Tip 2: Quick Formatting
Select text and use keyboard shortcuts for fastest formatting:
1. Type message
2. Select word
3. Press Ctrl+B
4. Done!

### Tip 3: Format While Typing
Use shortcuts without selecting text to insert formatted placeholders:
1. Press Ctrl+B
2. Type your text
3. Continue typing

### Tip 4: Works with Everything
Formatting works with:
- ✅ Mentions (@user, #group)
- ✅ Links (https://example.com)
- ✅ Emojis (🎉)
- ✅ Images and attachments
- ✅ Voice messages

## Troubleshooting

### Formatting Not Showing?
**Problem**: Text shows with `**` or `*` symbols

**Solution**: Make sure you're using the correct syntax:
- Bold: `**text**` (two asterisks)
- Italic: `*text*` (one asterisk)
- Underline: `__text__` (two underscores)
- Strikethrough: `~~text~~` (two tildes)

### Toolbar Not Appearing?
**Problem**: Can't see the three-dot icon

**Solution**: 
- Check you're in a chat conversation
- Make sure input is not disabled
- Try refreshing the page

### Keyboard Shortcuts Not Working?
**Problem**: Pressing Ctrl+B doesn't format text

**Solution**:
- Make sure you're focused in the message input
- On Mac, use Cmd instead of Ctrl
- Try using the toolbar instead

### Text Not Selected After Shortcut?
**Problem**: Placeholder "text" is not selected

**Solution**: This is normal - just start typing to replace it

## Best Practices

### Do's ✅
- Use **bold** for important information
- Use *italic* for subtle emphasis
- Use ~~strikethrough~~ for corrections
- Use __underline__ for key terms
- Combine formats for clarity

### Don'ts ❌
- Don't overuse formatting (loses impact)
- Don't format entire messages (hard to read)
- Don't use ALL CAPS with bold (too aggressive)
- Don't format every word (distracting)
