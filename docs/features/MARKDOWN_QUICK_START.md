# Markdown Formatting - Quick Start Guide

## 🚀 Start Using Markdown in 30 Seconds

### Step 1: Open Any Chat
Open a conversation with any user or group.

### Step 2: Type Your Message
Use these simple patterns:

```
**bold text**
*italic text*
~~strikethrough text~~
__underlined text__
```

### Step 3: Send It!
Press Enter (or tap Send) and watch your formatted message appear!

---

## 📝 The 4 Essential Formats

### 1. Bold - `**text**`
**When to use**: Important information, emphasis, headlines

**Example**:
```
This is **really important**!
```

---

### 2. Italic - `*text*` or `_text_`
**When to use**: Subtle emphasis, titles, thoughts

**Example**:
```
Have you read *The Great Gatsby*?
```

---

### 3. Strikethrough - `~~text~~`
**When to use**: Corrections, completed tasks, changes

**Example**:
```
Meeting is ~~Friday~~ Monday
```

---

### 4. Underline - `__text__`
**When to use**: Highlighting, key terms, emphasis

**Example**:
```
This is __very important__
```

---

## 💡 Quick Tips

### ✅ Do This
```
**bold**        ← Correct
*italic*        ← Correct
~~strike~~      ← Correct
__underline__   ← Correct
```

### ❌ Not This
```
** bold **      ← Spaces inside (won't work)
**bold*         ← Mismatched (won't work)
**incomplete    ← No closing (won't work)
```

## 🎯 Common Use Cases

### Making Announcements
```
@everyone **Important Update:**
Server maintenance tonight at __10 PM__
```

### Correcting Mistakes
```
The deadline is ~~Friday~~ **Monday**
```

### Creating Lists
```
**TODO:**
- ~~Buy milk~~ (done)
- Call dentist
- **Finish report** (urgent!)
```

### Emphasizing Points
```
Remember: **Always** backup your data!
```

## 🐛 Troubleshooting

### Not Working?
1. Check your syntax (opening and closing markers must match)
2. Remove spaces inside markers
3. Make sure you have both opening and closing markers
4. Refresh the page if needed
