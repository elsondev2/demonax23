# Markdown Formatting Examples

## Quick Reference Card

Copy and paste these examples directly into your messages!

### Basic Formatting

```
**This text is bold**
*This text is italic*
_This text is also italic_
~~This text is strikethrough~~
__This text is underlined__
```

## Formatting Tips

### Do's ✅
- Use **bold** for emphasis and important information
- Use *italic* for subtle emphasis or titles
- Use ~~strikethrough~~ for corrections or completed items
- Use __underline__ for highlighting key terms
- Combine formats for better communication

### Don'ts ❌
- Don't overuse formatting - it loses impact
- Don't use ALL CAPS with bold (too aggressive)
- Don't format entire messages (hard to read)
- Don't use formatting in place of clear communication

## Keyboard Shortcuts (for faster typing)

While typing your message:
- Type `**` before and after text for bold
- Type `*` or `_` before and after text for italic
- Type `~~` before and after text for strikethrough
- Type `__` before and after text for underline

## Troubleshooting

### Formatting Not Working?

1. **Check your syntax**: Make sure opening and closing markers match
   - ❌ `**bold*` (mismatched)
   - ✅ `**bold**` (correct)

2. **No spaces inside markers**:
   - ❌ `** bold **` (spaces inside)
   - ✅ `**bold**` (no spaces)

3. **Complete the pattern**:
   - ❌ `**incomplete` (no closing)
   - ✅ `**complete**` (both markers)
